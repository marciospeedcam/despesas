# Despesas

App para dividir despesas em grupo (PWA, GitHub Pages + Firebase).

- Quem cria o grupo vira administrador (senha curta).
- Os outros entram pelo link do convite e colocam o nome.
- Divide por quantas pessoas o grupo tiver.
- À vista, parcelado e cartão de crédito (quem pagou no cartão já consta como pago; os outros reembolsam a parte deles mês a mês).
- Nota e comprovante anexados (foto ou PDF).
- Despesa lançada por quem não é administrador fica **aguardando aprovação** e só entra na conta depois do "Aprovar".
- Chaves Pix por pessoa e sugestão de acerto.
